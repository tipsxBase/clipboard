# 使用指南

## 基础操作

### 唤出界面

默认情况下，您可以使用以下全局快捷键唤出剪贴板历史面板：

- **macOS**: `Cmd + Shift + V`
- **Windows / Linux**: `Ctrl + Shift + V`

> **提示**: 您可以在应用的设置页面修改此快捷键。

### 截图工具

内置的截图工具允许您捕获和标注屏幕内容：

#### 进行截图

1. **触发截图**: 使用配置的快捷键或菜单选项进入截图模式。
2. **选择区域**: 点击并拖动以选择要捕获的区域。您还可以：
   - **双击**任意位置捕获全屏
   - **单击**选择小区域（会自动扩展为全屏）
3. **调整选区**: 拖动边缘或角落来调整选区大小。

#### 标注工具

选择区域后，会出现一个工具栏，包含以下工具：

- **矩形** (□): 绘制矩形形状
- **椭圆** (○): 绘制圆形/椭圆形状
- **箭头** (→): 绘制箭头指向特定区域
- **画笔** (✎): 自由绘制
- **文字** (T): 添加文字标注

对于每个工具，您可以自定义：
- **颜色**: 从预设颜色中选择
- **线条粗细**: 调整粗细（文字工具除外）

#### 保存或取消

- **保存**: 按 `Enter` 或点击勾选 (✓) 按钮将截图保存到剪贴板
- **下载**: 点击下载按钮将截图保存为文件
- **重新选择**: 点击重置按钮清除选区并重新开始
- **取消**: 按 `Esc` 或点击 X 按钮退出而不保存

#### macOS 屏幕录制权限

> **macOS 用户重要提示**

在 macOS 10.15 (Catalina) 及更高版本上，应用需要明确的权限才能录制屏幕。首次使用截图功能时：

1. macOS 会显示权限对话框，请求**屏幕录制**访问权限
2. 点击**"允许"**授予权限
3. **重启应用程序**使权限生效

如果对话框没有出现或您不小心拒绝了权限：

1. 打开**系统设置**（或系统偏好设置）
2. 进入**隐私与安全性** > **屏幕录制**
3. 在列表中找到并勾选 **"Clipboard Manager"**
4. **重启应用程序**

如果没有此权限，截图将只能捕获桌面背景，无法捕获其他应用程序窗口。

### 列表导航

为了提高效率，我们支持多种导航方式，让您的双手无需离开键盘：

- **上下移动**:
  - 方向键 `↑` / `↓`
  - Vim 风格 `j` (下) / `k` (上)
  - Emacs 风格 `Ctrl+n` (下) / `Ctrl+p` (上)
- **确认/粘贴**: 按下 `Enter` 键将选中的内容粘贴到当前活动窗口，并自动关闭面板。
- **预览详情**: 按下 `Space` (空格键) 查看当前选中项的详细信息（适用于长文本或大图）。再次按下 `Space` 关闭预览。
- **关闭面板**: 按 `Esc`。

## 高级功能

### 粘贴队列 (Paste Stack)

粘贴队列允许你一次性复制多个项目，并按顺序依次粘贴。这在填写表单或在应用程序之间移动数据时非常有用。

### 2026 新特性

- **异步 OCR**：图片文字识别在 Windows/macOS 上已全面异步化，彻底解决死锁和数据库锁定问题。
- **历史保护**：清空历史时默认保护已收藏/置顶内容，并弹出确认对话框。
- **剪贴板项编辑/新增**：现在可在主界面直接新增或编辑文本、代码、网址、邮箱、电话等类型的剪贴板项（暂不支持图片），点击“编辑”或“新增”按钮即可。
- **数据库可靠性提升**：所有数据库操作均为异步，OCR 或历史操作时应用始终流畅。
- **托盘与界面同步**：托盘菜单与主界面状态始终保持同步，体验更顺畅。

1.  **选择项目**:
    - **键盘**: 导航到项目并按 `x` 键进行选择/取消选择。
    - **鼠标**: 按住 `Cmd` (macOS) 或 `Ctrl` (Windows) 并点击项目。
    - 选中的项目上会出现数字标记（如 ①, ②），指示粘贴顺序。
2.  **启动队列**: 按 `Enter` 键。第一个项目将被复制到剪贴板，窗口关闭。
3.  **按顺序粘贴**:
    - 粘贴第一个项目 (`Cmd+V`)。
    - 按下 **全局快捷键** (默认 `Cmd+Shift+V`)，程序会自动将队列中的 _下一个_ 项目复制到剪贴板。
    - 重复此操作直到队列为空。

### OCR (文字识别)

> **注意**: 目前支持 macOS 和 Windows。

你可以直接从剪贴板历史记录中的图片提取文字。

1.  在列表中选中一个图片项目。
2.  按 `Space` 键打开预览。
3.  点击右下角的 **"提取文字"** 按钮。
4.  提取的文字将自动复制到剪贴板，并作为一个新的文本项目添加到历史记录中。

### 紧凑模式

如果你喜欢更紧凑的信息视图，可以在设置中开启 **紧凑模式**。该模式会：

- 减小每个列表项的高度。
- 在列表中隐藏图片预览（显示 `[Image]` 文本）。
- 在屏幕上显示更多项目。

### 置顶项目

您可以将重要的项目置顶显示。置顶的项目将：

- 始终显示在历史记录列表的顶部。
- **不会被自动删除**，即使达到了历史记录数量限制。

要置顶一个项目，请将鼠标悬停在项目上并点击置顶图标。

### 敏感数据

您可以将项目标记为“敏感”。敏感项目将：

- 在数据库中加密存储。
- 在界面上模糊显示，直到鼠标悬停。

> **注意**: 为了防止误报，基于熵值的自动敏感内容检测已被移除。您仍然可以在设置中配置“敏感应用”，以忽略来自特定应用（如密码管理器）的剪贴板内容。

## 搜索功能

面板顶部设有搜索框。打开面板后，直接输入关键词即可过滤历史记录。

- 支持模糊搜索。
- 搜索范围包括文本内容和来源应用名称。

## 数据管理

### 存储位置

为了保障您的数据隐私，所有数据均存储在您的本地设备上：

- **macOS**: `~/.clipboard-manager/`
- **Windows**: `C:\Users\<Username>\.clipboard-manager\`
- **Linux**: `~/.clipboard-manager/`

### 数据库安全

- 数据库文件名为 `history.db`。
- 数据库使用 **AES-GCM** 算法进行加密，密钥存储在本地安全位置。这意味着即使有人获取了您的数据库文件，没有密钥也无法读取其中的内容。

### 隐私设置

在设置中，您可以：

- **暂停记录**: 暂时停止监听剪贴板变化。
- **忽略应用**: 添加不需要记录的应用名称（如 `1Password`, `KeyChain` 等），保护敏感信息。
- **清空历史**: 一键删除所有本地存储的历史记录。
