截图工具

剪贴板管理器包含一个强大的内置截图工具，让您可以轻松捕获、标注和保存截图。

快速开始​

  1. 触发截图: 使用配置的快捷键（在设置中查看）或从菜单中选择"截图"
  2. 选择区域: 点击并拖动以选择要捕获的区域
  3. 标注（可选）: 使用工具栏添加形状、箭头、文字或绘图
  4. 保存: 按 Enter 或点击勾选按钮保存到剪贴板

捕获截图​

选择方法​

  • 点击并拖动: 在一个角点击并拖动到对角以选择矩形区域
  • 双击: 双击任意位置捕获整个屏幕
  • 单击（小区域）: 如果您快速点击并释放（创建一个很小的选区），它会自动扩展为全屏

调整选区​

创建选区后，您可以：

  • 调整大小: 拖动选区框的边缘或角落
  • 移动: 在选区内点击并拖动以重新定位（仅在添加标注之前有效）

标注工具​

选择区域后，底部会出现一个工具栏，包含各种标注工具：

可用工具​

工具图标描述可自定义选项
矩形□绘制矩形形状颜色、线条粗细
椭圆○绘制圆形或椭圆形状颜色、线条粗细
箭头→绘制箭头指向特定区域颜色、线条粗细
画笔✎自由绘制颜色、线条粗细
文字T添加文字标注颜色、字体大小

自定义选项​

对于每个工具，您可以自定义：

  • 颜色: 点击颜色选择器从预设颜色中选择（红、黄、绿、蓝、紫、白、灰、黑）
  • 线条粗细: 点击大小选择器从 3 个预设大小中选择（细、中、粗）
  • 字体大小（仅文字工具）: 根据文字内容自动调整

使用标注工具​

  1. 选择工具: 点击工具栏中的工具按钮
  2. 自定义（可选）: 选择您喜欢的颜色和线条粗细
  3. 绘制: 在截图上点击并拖动以创建标注
  4. 取消选择工具: 再次点击相同的工具按钮以取消选择

撤销/重做​

  • 撤销: 点击撤销按钮 (↶) 或按 Ctrl+Z / Cmd+Z
  • 重做: 点击重做按钮 (↷) 或按 Ctrl+Y / Cmd+Shift+Z

保存截图​

您有多种保存截图的选项：

保存到剪贴板​

  • 键盘: 按 Enter
  • 鼠标: 点击工具栏中的勾选 (✓) 按钮

截图将：

  1. 保存到剪贴板（可以用 Ctrl+V / Cmd+V 粘贴）
  2. 添加到剪贴板历史记录
  3. 自动保存到捕获文件夹

下载为文件​

  • 点击工具栏中的下载 (⬇) 按钮
  • 截图将保存到默认下载文件夹，文件名包含时间戳

取消​

  • 键盘: 按 Esc
  • 鼠标: 点击工具栏中的 X 按钮

macOS 屏幕录制权限​

为什么需要权限？​

在 macOS 10.15 (Catalina) 及更高版本上，Apple 要求应用明确请求权限才能录制屏幕。这是一项隐私保护措施，防止未经授权的屏幕捕获。

如果没有此权限，截图工具只能捕获：

  • ✅ 桌面背景
  • ✅ 应用自己的窗口
  • ❌ 其他应用程序窗口（这就是问题所在！）

授予权限​

首次设置​

首次使用截图功能时，macOS 会自动显示权限对话框：

"Clipboard Manager" 想要录制您的屏幕。

这允许应用捕获整个屏幕的截图，
包括其他应用程序。

[拒绝]  [允许]
  1. 点击**"允许"**
  2. 重启应用程序（非常重要！）

手动设置​

如果对话框没有出现或您不小心拒绝了权限：

  1. 打开系统设置（或旧版 macOS 上的系统偏好设置）
  2. 导航到隐私与安全性 > 屏幕录制
  3. 在列表中查找 "Clipboard Manager"
  4. 勾选旁边的复选框
  5. 重启应用程序

故障排除​

问题：截图只显示桌面背景​

解决方案: 这意味着屏幕录制权限尚未授予。按照上面的手动设置步骤操作。

问题：权限对话框没有出现​

可能原因:

  • 应用已在屏幕录制列表中（手动检查）
  • 您正在运行开发模式（构建发布版本进行测试）
  • 应用未正确签名（开发中预期）

解决方案: 按照上述说明在系统设置中手动添加应用。

问题：已授予权限但仍然无法工作​

解决方案:

  1. 在屏幕录制设置中取消勾选应用
  2. 再次勾选
  3. 重启应用
  4. 如果仍然无法工作，重启 Mac

键盘快捷键​

操作快捷键
确认/保存Enter
取消Esc
撤销Ctrl+Z / Cmd+Z
重做Ctrl+Y / Cmd+Shift+Z

提示和技巧​

  1. 快速全屏: 双击任意位置立即捕获全屏
  2. 精确选择: 按住 Shift 拖动以创建完美的正方形选区（即将推出）
  3. 颜色一致性: 工具会记住您上次使用的颜色和线条粗细
  4. 多个标注: 您可以在保存前添加任意数量的标注
  5. 保存前预览: 慢慢来查看和标注 - 在按 Enter 之前不会保存任何内容

技术细节​

  • 图片格式: 截图保存为 PNG 文件以获得最高质量
  • 存储位置:
    • 临时文件: ~/.clipboard-manager/cache/screenshots/
    • 保存的捕获: ~/.clipboard-manager/captures/
  • 清理: 关闭截图窗口时会自动清理临时文件
  • 多显示器支持: 该工具可在多个显示器上无缝工作

已知限制​

  • 仅 macOS: 屏幕录制权限仅在 macOS 上需要
  • 开发模式: 权限对话框在开发模式（cargo tauri dev）下可能无法正常工作。使用 cargo tauri build 测试发布版本。
  • Wayland (Linux): 某些使用 Wayland 的 Linux 桌面环境可能对截图支持有限
